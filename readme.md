## ✦ À propos

Luma Studio est un éditeur graphique web léger, pensé pour composer et retoucher des visuels sans installer de logiciel. Importez une image ou partez d’une feuille blanche, ajoutez vos éléments, puis exportez votre création.

## ◈ Ce que vous pouvez faire

| Créer | Personnaliser | Exporter |
|:--|:--|:--|
| Affiches et visuels sociaux | Texte, logos et calques | PNG, JPG et WebP |
| Compositions et collages photo | Couleurs, polices et filtres | Projet réouvrable |
| Formats portrait, carré et paysage | Fonds, cadres et effets | Enregistrement local |

- Organiser les calques : déplacement, ordre, verrouillage et visibilité.
- Retoucher les images : luminosité, contraste, saturation, température et flou.
- Travailler sur une feuille blanche, une photo ou un modèle prêt à personnaliser.
- Utiliser les panneaux latéraux sur tablette et mobile grâce aux menus hamburger.
- Reprendre son travail avec la sauvegarde automatique sur l’appareil.

## ⌘ Démarrer

Le site est statique : aucun outil de compilation ni installation de dépendances n’est nécessaire.

### Ouvrir directement

Ouvrez [`index.html`](index.html) dans votre navigateur.

### Lancer un serveur local

À la racine du dépôt, exécutez :

```bash
python -m http.server 8000
```

Puis ouvrez [http://localhost:8000](http://localhost:8000).

> Un serveur local est recommandé pour que toutes les ressources et fonctions du navigateur se comportent correctement.
